# «Глиссада-6» — реконструкция игры «Глиссада» для БЭСМ-6

**БЭСМ-6 · ОС ДИСПАК («Дубна») · транслятор ФОРТРАН ИПМ (ФОРЭКС) · АЦПУ · Паскаль**

Реконструкция игры-тренажёра захода на посадку «Глиссада» в вычислительных
технологиях 1975–1980 гг. Оригинальные исходники игры публично не обнаружены;
пакет написан заново как добросовестная реконструкция эпохи.

## Что моделируется

- посадка по глиссаде **3°** с вводом с **15 км** (высота 786 м);
- пять типов самолётов: **МиГ-15, Ил-28, Ту-104, Ан-24, Ан-2** (посадочная конфигурация);
- **шесть степеней свободы**, ориентация — кватернионом (13-компонентный
  вектор состояния), интегрирование Рунге–Кутта 4-го порядка, шаг **0,1 с**;
- турбулентность — фильтр Орнштейна–Уленбека по трём каналам;
- **контроль точности** по Кутта–Мерсону резервной подпрограммой
  `SRC/GLKM.FTN` (вместо недоступной подпрограммы СБ `АД01`);
- двигатели ТРД и ТВД (упрощённые дроссельные характеристики);
- два режима: **АВТОМАТ** (автопилот захода) и **ПРОГРАММА** (пилотирование
  задано колодой карт — в этом состоит игра);
- два способа запуска: **классическая колода** ФОРТРАН и **интерактивный
  диалог**, где Паскаль печатает поле, а Fortran-ядро считается из PERSO;
- вывод: кадр на **АЦПУ** (профиль, план сверху, две шкалы) и итоговая
  **оценка посадки**.

## Принцип аутентичности

Никаких современных приёмов. Использовано только то, что было в
подмножестве Фортрана 66-го года на БЭСМ-6:

- фиксированный формат колод: колонки 1–72, продолжения в колонке 6;
- нет блочных `IF`, нет типа `CHARACTER`, нет структур;
- русский текст на АЦПУ — только Холлеритом (ГОСТ 10859);
- управление — вычисляемые `GOTO`, арифметические `IF`;
- случайные числа — генератор Лемера (СБ `АВ07` недоступна, работает запасной адаптер).

Тексты исходников и колод проходят машинную проверку (колонки, продолжения,
счётчики Холлерита) — см. раздел «Сборка и проверка».

## Исходные данные

**Карта 1 (5I5):**

| Поле | Смысл | Значения |
|------|-------|----------|
| 1 | ТИП | 1–МиГ-15, 2–Ил-28, 3–Ту-104, 4–Ан-24, 5–Ан-2 |
| 2 | РЕЖИМ | 1–АВТОМАТ, 2–ПРОГРАММА |
| 3 | КОНТРОЛЬ | 0 — выключен; >0 — контроль Кутта–Мерсона (в диалоге — 2) |
| 4 | ПЕЧАТЬ | период кадра АЦПУ, с (0 — только касание) |
| 5 | БИБЛ.СБ | 1 — вызовы СБ, 0 — запасные программы |

**Карта 2 (4F8.0):** ВРЕМЯ МАКС (с), СЕМЯ СЛУЧ.ЧИСЕЛ, СИГМА ТУРБУЛЕНТНОСТИ
(м/с, 0 — штиль), НАЧАЛЬНАЯ ТЯГА (0–1).

**Режим ПРОГРАММА:** далее карты (5F8.0) `Т, РУЛЬ ВЫС (гр), ЭЛЕРОНЫ (гр),
РУЛЬ НАПРАВЛЕНИЯ (гр), ТЯГА (0–1)`; линейная интерполяция между картами;
конец — карта с `Т < 0`.

## Запуск

### Классическая колода

1. Собрать симулятор БЭСМ-6 и получить образы ДИСПАК — см. `docs/ETAP0.TXT`.
2. Подать колоду `JOB/GLISSADA.B6` на утилиту `dispak` (обвязка
   `TOOLS/run_save_pty.py` отвечает на приглашение `WHAT=`).
3. Для других вариантов заменить карты данных после `*execute` содержимым
   `DATA/GLIS1.DAT`, `DATA/GLIS2.DAT` или `DATA/GLIS1-T5.DAT`.
4. Поле `БИБЛ.СБ = 0`: работают запасные программы МСА и генератор Лемера.

### Интерактивный диалог (рекомендуется)

```bash
cd ~/Yandex.Disk/re-glissade
sh TOOLS/install-2348.sh 1
python3 TOOLS/calib/verify_all.py 1.5
python3 TOOLS/calib/scenarios.py verify
```

Ядро и оболочка записываются в `~/.besm6/2348`, зона `2700(8)`. Диск
предварительно очищается через `besmtool zero`; создаётся резервная копия.
Подробности — `docs/PLAN-DIALOG.md`, раздел 10.

## Библиотека СБ (том 2048)

Используются процедуры по каталогу СБ (Мазный М.С. «БЭСМ-6. Система
программирования “Дубна”», Наука, 1978, с. 128–139):

- `CALL ATM(HG,TK,RHO)` — стандартная атмосфера, катал. **АЗ01**;
- `CALL NR(RN)` — нормальная случайная величина, катал. **АВ07**;
- **АД01** (Кутта–Мерсон) — заменена резервной подпрограммой `SRC/GLKM.FTN`.

Обращения к недоступным процедурам собраны в `SRC/GLNUM.FTN`; запасной
адаптер — `SRC/GLNUMR.FTN`.

## Этапы проекта

- **Этап 0** — среда: сборка simh-BESM-6, образы ДИСПАК, том 2048 (`docs/ETAP0.TXT`);
- **Этап 1** — настройка: сигнатуры СБ, устройства 5/6/12, кириллица,
  наладка автопилота (`docs/ETAP1.TXT`);
- **Этап 2** — уточнение ТТХ по документам, перекалибровка, исторические
  сценарии, контроль Кутта–Мерсона (`docs/analysis/ttx-audit.md`,
  `docs/analysis/etalon-pogoda.md`, `docs/analysis/kutta-merson.md`).
- **Этап 3** — диалог на Паскале и PERSO-библиотека зоны 2700(8)
  (`docs/PLAN-DIALOG.md`, `docs/DIALOG-FIELD.md`).

## Сборка и проверка колод

Колоды имеют фиксированный формат; контроль выполняется скриптом
`TOOLS/CHECK-DECK.PY`: колонки 1–72, запрет табуляции, целостность
продолжений, соответствие счётчиков Холлерита длине строки. Генератор
`TOOLS/build-dialog.py` пересобирает PERSO-колоды из свежего `SRC/`.

## Статус

### Историческая справка: состояние после этапа 0

v0.2: скелет пакета и первый прогон в среде (этапы 0–1, пакетный
эмулятор dispak, Монитор-80 ИАЭ, том 2048):

- трансляция ФОРЭКС всех модулей — без ошибок (обе комплектации);
- контрольный тест среды (решето, `*forex`) — пройден;
- загрузка: с `GLNUM` процедуры СБ `NR`/`ATM` не найдены в комплекте
  образов, с резервным `GLNUMR` — загрузка полная;
- печать АЦПУ: только латиница (кириллица Холлерита даёт I/O-error 205);
- том диска для ввода задачи **НЕ НУЖЕН** — МОНА-80 спулирует входной поток
  на барабан. Карта «ЛЕН 45(202-ЗП)» была только в экспериментальных
  прогонах; генераторы тома 202 — стендовые, направление закрыто.
