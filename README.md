# «Глиссада-6» — реконструкция игры «Глиссада» для БЭСМ-6

**БЭСМ-6 · ОС ДИСПАК («Дубна») · транслятор ФОРТРАН ИПМ (ФОРЭКС) · АЦПУ**

Реконструкция игры-тренажёра захода на посадку «Глиссада» в вычислительных
технологиях 1975–1980 гг. Оригинальные исходники игры публично не обнаружены;
пакет написан заново как добросовестная реконструкция эпохи.

## Что моделируется

- посадка по глиссаде **3°** с вводом с **15 км** (высота 786 м);
- четыре типа самолётов: **МиГ-15, Ил-28, Ту-104, Ан-24** (посадочная конфигурация);
- **шесть степеней свободы**, ориентация — кватернионом (13-компонентный
  вектор состояния), интегрирование Рунге–Кутты 4-го порядка, шаг **0,1 с**;
- турбулентность — фильтр Орнштейна–Уленбека по трём каналам;
- двигатели ТРД и ТВД (упрощённые дроссельные характеристики);
- два режима: **АВТОМАТ** (автопилот захода) и **ПРОГРАММА** (пилотирование
  задано колодой карт — в этом состоит игра);
- вывод: кадр на **АЦПУ** (с курсором отклонения от глиссады) и короткая
  строка на **дисплей**; итоговая **оценка посадки**.

## Принцип аутентичности

Никаких современных приёмов. Использовано только то, что было в
подмножестве Фортрана 66-го года на БЭСМ-6:

- фиксированный формат колод: колонки 1–72, продолжения в колонке 6;
- нет блочных `IF`, нет типа `CHARACTER`, нет структур;
- русский текст на АЦПУ — только Холлеритом (ГОСТ 10859);
- управление — вычисляемые `GOTO`, арифметические `IF`;
- случайные числа — генератор Лемера и процедуры Стандартной библиотеки.

Тексты исходников и колод проходят машинную проверку (колонки, продолжения,
счётчики Холлерита) — см. раздел «Сборка и проверка».

## Исходные данные

**Карта 1 (5I5):**

| Поле | Смысл | Значения |
|------|-------|----------|
| 1 | ТИП | 1–МиГ-15, 2–Ил-28, 3–Ту-104, 4–Ан-24 |
| 2 | РЕЖИМ | 1–АВТОМАТ, 2–ПРОГРАММА |
| 3 | КОНТРОЛЬ | зарезервировано (Кутта–Мерсон, СБ АД01) |
| 4 | ПЕЧАТЬ | период кадра АЦПУ, с (0 — только касание) |
| 5 | БИБЛ.СБ | 1 — вызовы СБ, 0 — запасные программы |

**Карта 2 (4F8.0):** ВРЕМЯ МАКС (с), СЕМЯ СЛУЧ.ЧИСЕЛ, СИГМА ТУРБУЛЕНТНОСТИ
(м/с, 0 — штиль), НАЧАЛЬНАЯ ТЯГА (0–1).

**Режим ПРОГРАММА:** далее карты (5F8.0) `Т, РУЛЬ ВЫС (гр), ЭЛЕРОНЫ (гр),
РУЛЬ НАПРАВЛЕНИЯ (гр), ТЯГА (0–1)`; линейная интерполяция между картами;
конец — карта с `Т < 0`.

## Запуск

1. Собрать симулятор БЭСМ-6 и получить образы ДИСПАК — см. `docs/ETAP0.TXT`.
2. Подать колоду `JOB/GLISSADA.JOB` на читалку перфокарт (утилита `dispak`
   или подключение текстового файла — по документации репозитория `dispak`).
3. Для других вариантов заменить карты данных после карты `*DATA` содержимым
   `DATA/GLIS1.DAT` или `DATA/GLIS2.DAT`.
4. Пока не проверена библиотека СБ, работать с полем `БИБЛ.СБ = 0`
   (запасные программы МСА и генератор Лемера — в `SRC/GLNUM.FTN`).

## Библиотека СБ (том 2048)

Используются процедуры по каталогу СБ (Мазный М.С. «БЭСМ-6. Система
программирования “Дубна”», Наука, 1978, с. 128–139):

- `CALL ATM(HG,TK,RHO)` — стандартная атмосфера, катал. **АЗ01**;
- `CALL NR(RN)` — нормальная случайная величина, катал. **АВ07**;
- зарезервировано: метод Кутта–Мерсона, катал. **АД01** (контроль точности).

Все обращения собраны в `SRC/GLNUM.FTN`: при расхождении фактических
сигнатур правится только этот файл. Сигнатуры подлежат проверке на этапе 1.

## Этапы проекта

- **Этап 0** — среда: сборка simh-BESM-6, образы ДИСПАК и тома 2048 (`docs/ETAP0.TXT`);
- **Этап 1** — настройка: проверка сигнатур СБ, привязка устройств 5/6/12,
  кириллица Холлерита, наладка автопилота по всем 4 типам (`docs/ETAP1.TXT`);
- **Этап 2** — уточнение коэффициентов по отчётам ОКБ/ЦАГИ, подбор карт
  режима ПРОГРАММА для каждого типа, контроль по Кутта–Мерсону.

## Сборка и проверка колод

Колоды имеют фиксированный формат; контроль выполняется скриптом
(`scripts/check_deck.py` в рабочем каталоге проекта): колонки 1–72,
запрет табуляции, целостность продолжений, соответствие счётчиков
Холлерита длине строки. Проверка пройдена для всех файлов `SRC/` и `DATA/`.
