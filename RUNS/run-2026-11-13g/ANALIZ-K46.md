## Механизм (MTR 05340-05500 k12-mtr + WATCH0 75442 + ядро 00411)
- Оба Э70 идут через один билдер 05452-05456 и точку 05420
  (Э70 0003(11), УС на 75502). УС = [05474]<<0 | [М17=75506] (0o0370...)
  | [75442]<<12. Печатается "CW 75502 ...".
- Цикл 05004-05043 = экстрактор ЛУНа; итерации по WATCH0:
  atx [75442]:=45 -> GIVELEXX -> Э70 u=45 ОК -> (М4=М5=0o44 = POINT!)
  aax [75442] -> atx [75442]:=45 (2-й проход той же записи 0520, без
  Э70) -> (М4=М5=0o76) aax -> atx [75442]:=46 (М13=00522) -> Э70 u=46.
  М3=01132=ВСDREAD* в части итераций - цикл получает лексему чтения.
- GIVELEXX вызывается дважды с полностью разными состояниями регистров
  (2-й вход: М15=04300, М6=02350, М7=02375) - свежий вызов "за листом".
