# АНАЛИЗ K12: читатель прошёл конверт (А2, 13.11-9, п.18.10(1))

## Что сделано
Сид k12 = первый конверт из цепочки записей по 0o32 (сетка границ
0o12+0o32k, п.18.9в): маркер [11201] на каждой границе, карта
(12 слов ISO 72 кол. + эталон EOR) + филлер ISO-пробелов до границы,
[11200]@0o130. Записи: card1, card2, *end file. Запись 1 (тракт 5) =
нули + [11200]@0o12. Генератор: TOOLS/mk_seed_k12.py.

## Результат (k12-run, повторы k12-rep1/2 стабильны)
- "ИСПОРЧЕН РЕКОРД" ИСЧЕЗ. Границы 0o12/0o44/0o76/0o130 = типы 0/0/0/3
  (XOR-тест п.18.9б). ERRIOM нет, 201 нет.
- Новая смерть: "ОШ.В ИНФ.СЛ.ЭКСТ", СТП pc=05420, acc=0010370000460000.
  READ(5) не завершился: IA/B (01121-01131) = нули (k12-core522).

## Цепочка (MTR 05340-05500 + WATCH 75442 + дамп ядра)
1. Успешный Э70: УС [75502]=0o0010370000450000 = чтение целой зоны
   с u=45 в лист 37000. LUN45 redirect -> барабан 020 тракт 04 (наш
   конверт). Штатный обмен с сидом РАБОТАЕТ.
2. Смерть: УС [75502]=0o0010370000460000 (тот же шаблон, юнит 46).
   ddio: disks[46].diskno=0 -> E_CWERR -> "ОШ.В ИНФ.СЛ.ЭКСТ".
3. Механизм: GIVЕLЕХХ (05355) перебирает ЛУН-таблицу [0510]-[0547]:
   [75442] := 45, 45, 46 (atx 0(12) @05021, М13: 0520->0520->0522).
   УС = шаблон [5474]=0o0010370000000000 | ЛУН<<12.
   Первый ЛУН45 дал Э70, второй проход по 45 - без Э70 (цикл
   перебора 05022-05043), ЛУН46 - смерть.
4. Таблица [0510]-[0547] расшифрована: 4-битные ЛУНы 0o41..0o57
   ([0510]="...41...", [0520]="...45...", [0522]="...46...") + особая
   запись [0546]="...16..." / [0547]=0o176000. Второе слово записи =
   0o0000000037770000. УТОЧНЕНИЕ п.17: это ЛУНы устройств спула, а не
   каналы ФС.
5. АЦН (asn): величина сдвига = 64 - (код & 0x7f):
   0o64 -> <<12, 0o77 -> <<1, 0o160 -> <<16, 0o100 -> <<0 (в accex).
   Реализация: arith.c asx(), enreg.o = addr & 0x7f (cu.c GET_NAI_OP).

## Гипотеза
После обработки зоны ЛУН45 GIVЕЛEXX счёл лист исчерпанным (записи
прошли, POINT 0o44->0o76 в регистрах цикла) и пошёл за следующим
листом очереди -> ЛУН46 -> пусто -> E_CWERR. На реальной системе
очередь не пуста; у нас - некрасивая смерть вместо "конец очереди".
