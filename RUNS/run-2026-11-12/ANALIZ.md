## Задача 1: RUNS/GLIS1R.B6 (GLNUMR, резервный адаптер) — листинг GLIS1R-2026-11-12.log
- СТП-паспорт, Монитор-80 (3.7), трансляция ФОРЭКС 6 модулей — БЕЗ ОШИБОК;
- карта загрузки полная: PROGRAM E 01000, runtime BCDREAD*/BCDWRITE*/MONREAD*,
  GLAUTO 04316, PROIZV 04631, FRAME 05266, JUDG 06003; СВОБОД 12614 слов;
- счёт остановлен на первом READ(5): «ИСПОРЧЕН РЕКОРД LUN 5 RET 01744 DEV 00045
  CZ 00000 POINT 00012» → ERRIOM → КОНЕЦ ЗАДАЧИ.
- Трактовка (ETAP1, п. 9.2–9.8): RET 01744 = точка возврата в BCDREAD*,
  цепочка SREAD → RWBT → МОNRЕАД*; POINT 00012 (0o12) = смещение проверяемого
  слова листа в буфере обмена 76000; статус 0o21 = тип 1 «ИСПОРЧЕН РЕКОРД».
  Формат записи «REC»+80 симв.+EOR ещё не распознан пост-обработкой —
  заголовок листа (сл. 0 = 0o2204240 в образце с барабана, зона 1044) не
  воспроизведён в mk_tom45d.py. Это открытый блок А2.
