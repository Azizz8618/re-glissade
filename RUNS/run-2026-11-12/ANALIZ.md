  запись С КЛЮЧОМ (это НОРМА печати IOCONT* - KRECORD+K3HREC-ключ
  и карта), а I/O-ERROR 201 = КОНВЕРСИЯ I5: первое поле карты
  = «REC  » вместо «    3» -> конверсия падает.
  Т.Е. правильный лист имеет записи, ГДЕ КЛЮЧ «REC» стоит так,
  чтобы текст карты начинался С КОЛОНКИ 1 ПРИ ПЕРЕДАЧЕ - а монread%
  ключ НЕ скипает. Разрешение: карта должна начинаться СО СЛОВА 0
  записи, а «REC»-ключ - БЫТЬ СЛОВОМ ПЕРЕД ЗАПИСЬЮ на 25-словной
  границе, при этом передаётся запись ПОСЛЕ ключа... в e5 передано
  С ключа => монread% скипает МЕЖДУ ключами: после ключа передает
  слова ДО СЛЕДУЮЩЕГО ключа, но ключевой термин - начало записи...
  КОНТР-ТЕСТ (след. итерация): запись = [REC-key][1 слово «шапка»]
  [карта 13 слов] - если «шапка» попадает в текст вместо карты -
  монread% не скипает НИЧЕГО, и тогда единственная рабочая
  конфигурация: КЛЮЧ = ПЕРВОЕ СЛОВО КАРТЫ-ТЕКСТА, т.е. текст карты
  должен начинаться с «REC» - что бессмыслица => монread% СКИПАЕТ
  ровно ОДНО слово после классификатора - проверить дампом MONCARD*
  при успешном классе (CORE_ON_PC на выходе классификатора при
  СОВПАДЕНИИ - сконструировать лист, где слово 0o13 = КЛАСС
  (REC-слово с conv/маской из e12-таблицы классов... классы сняты!).

- e13 (классы таблицы М2 как слова записей): дамп ТОТ ЖЕ, но

## ШАГ 4 ФИНАЛЬНЫЙ СИНТЕЗ (аналитический):
ПОЛНАЯ ФОРМУЛА РАСКРЫТА: слова [М5] классификатора = МОНА-СПУЛ-
слова, причём word = class ^ 0o200000000200001 (K = conv-код 2 в
старших разрядах + байт 0o02 (LEN+2) + байт 0o01 (EOR 0o12 вместо
0o13 в классе)). Классификатор сравнивает СЫРЫЕ слова с классами
ТОЧНО (aex+uza) - не совпадает из-за K -> I/O-ERROR 201.
ЗНАЧИТ: правильный лист должен содержать слова = class (ТОЧНО),
а МОНА-спул кладёт class^K (МОНА-спул - РАБОЧАЯ копия с
служебными битами; дисковый лист-конверт - эталонный класс).
e13 УЖЕ содержал точные классы на словах 0 записей - НО
классификатор мог смотреть на ДРУГИЕ позиции (М5-динамика).
КЛЮЧЕВОЙ ПРОПУЩЕННЫЙ ЭКСПЕРИМЕНТ: MTR-трасса e13-прогона
(окно 37340-37430, снятие [М5]-последовательности при ТОЧНЫХ
классах) - покажет, ДОШЛО ЛИ сравнение до нуля (классифицировано)
и какое слово [М5] смотрится ПЕРВЫМ. После этого mk_tom45f
дописывается точным раскладом -> READ OK.
