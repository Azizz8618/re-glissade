# Задачи для эмулируемой СМ-2 (тренажёр «Глиссада-6»)

В этом каталоге лежат исходники задач на языке ассемблера СМ-2 и описание
результатов их прогона в эмуляторе SIMH `hp2100`.

## Состав

- `ps1.asm` — первая задача PS1: сложить NUM PS и PERIOD из Area дескриптора
  поля, записать сумму в OUT FLD и остановиться.

Ассемблер: `TOOLS/sm2asm.py`. Его синтаксис и поддерживаемые мнемоники
описаны в заголовке файла `sm2asm.py`.

## Кодировки, на которые опирается ассемблер

- Базовые команды MRG (из `HP2100/hp2100_sys.c`, `mrg_ops`): `AND 0010000`,
  `JSB 0014000`, `XOR 0020000`, `JMP 0024000`, `IOR 0030000`, `ISZ 0034000`,
  `ADA 0040000`, `ADB 0044000`, `CPA 0050000`, `CPB 0054000`, `LDA 0060000`,
  `LDB 0064000`, `STA 0070000`, `STB 0074000`. Адресное поле — разряды 0-8
  (`0000777`), то есть нулевая страница.
- `HLT` — из IOG-таблицы (`iog_ops`), кодировка `0102000`.
- Расширенные команды СМ-2 — из `HP2100/sm2_params.h` и таблицы `sm2_ops` в
  `hp2100_sys.c`: `DLD 001100`, `DST 001200`, `MPY 000100`, `DIV 000200`,
  `LDX 001104`, `LDY 001105`, `STX 001204`, `STY 001205`, `LBN 001101`,
  `LBP 001102`, `FAD 001400`, `FSB 001410`, `FMP 001420`, `FDV 001430`,
  `TAS 001107`, `FIX 0105100`, `FLT 0105120`, `ASR 000011`, `ASL 000001`,
  `LSR 000012`, `LSL 000002`, `RRR 000014`, `RRL 000004`.
  В текущей реализации эмулятора `SM2_OP(IR) = IR & 0177777`, поэтому слово
  расширенной команды должно в точности равняться коду из таблицы; второе
  слово (адрес или непосредственный операнд) используют все расширенные
  команды, кроме сдвигов.

## Сборка

Из корня репозитория:

```sh
python3 TOOLS/sm2asm.py TOOLS/sm2_tasks/ps1.asm -o /tmp/ps1.ini
```

Ассемблер создаёт:

- `/tmp/ps1.ini` — SIMH-скрипт с `SET CPU SM2`, `DEPOSIT`-ами, `DEPOSIT P`,
  `RUN`, `EXAMINE OUT` и `QUIT`;
- `/tmp/ps1.map` — текстовый дамп слов (адрес → слово) рядом со скриптом.

Полный вид скрипта:

```text
; Сгенерировано sm2asm.py на основе ps1.asm
; Адреса и слова — восьмеричные (SIMH по умолчанию).
SET CPU SM2
DEPOSIT 000000 060010
DEPOSIT 000001 040011
DEPOSIT 000002 070012
DEPOSIT 000003 102000
DEPOSIT 000010 000005
DEPOSIT 000011 000007
DEPOSIT 000012 000000
DEPOSIT P 00000
RUN
EXAMINE 000012
QUIT
```

Расшифровка слов:

| Адрес | Слово  | Команда / данные |
|-------|--------|------------------|
| 000000 | 060010 | `LDA NUM` (NUM PS = 5) |
| 000001 | 040011 | `ADA PERIOD` (PERIOD = 7) |
| 000002 | 070012 | `STA OUT` |
| 000003 | 102000 | `HLT` |
| 000010 | 000005 | NUM PS |
| 000011 | 000007 | PERIOD |
| 000012 | 000000 | OUT FLD (результат) |

## Прогон в эмуляторе

Команда (из каталога `/home/azizz/Yandex.Disk/simh`):

```sh
./BIN/hp2100 < /tmp/ps1.ini
```

Полученный вывод:

```text
Programmed halt, T: 000000 (NOP), P: 00004 (NOP)
sim> 12:	000014
sim> Goodbye
```

`EXAMINE 000012` вернул `000014` (восьмеричное) = 12 (десятичное), что
в точности равно `NUM PS + PERIOD = 5 + 7`. Программа остановилась по `HLT`
на адресе `00004` (следующая за HLT ячейка). Результат зафиксирован.

## Тесты

```sh
python3 -m unittest discover -s TOOLS/tests -p 'test_sm2asm.py' -v
```

В наборе есть интеграционный тест: если бинарник
`/home/azizz/Yandex.Disk/simh/BIN/hp2100` присутствует, он собирает `ps1.asm`,
прогоняет скрипт в эмуляторе и проверяет, что `EXAMINE 12` возвращает
`000014`.
