# КАК ИГРАТЬ В «ГЛИССАДУ-6»

## Суть игры

Самолёт заходит на посадку по глиссаде — наклонной линии под углом три
градуса. В начале захода он находится в пятнадцати километрах от полосы
на высоте 786 метров. Нужно довести самолёт до касания так, чтобы:

- касание произошло как можно ближе к порогу полосы, но не раньше него;
- вертикальная скорость касания была как можно меньше;
- отклонение от глиссады за весь заход было небольшим.

В конце программа печатает оценку: «отлично», «хорошо»,
«удовлетворительно» или «жёсткая посадка» (`OCENKA= 1..4`, где 1 —
лучшая), а также точку касания, смещение от оси полосы и отклонение
от глиссады.

## Два способа играть

| Способ | Что нужно | Где лежит |
|---|---|---|
| **Интерактивный диалог** (рекомендуется) | том 2348 с PERSO-зоной 2700, колода вызова | `JOB/GLCALL-2700.B6` |
| **Колода перфокарт** (классический режим) | Fortran-колода, карты данных и управления | `JOB/GLISSADA.B6`, `DATA/PROGRAM/` |

В диалоге управление берёт на себя Pascal-оболочка, а модель считает
Fortran-ядро из PERSO. В колоде перфокарт всё делает Fortran-программа
`GLMAIN`. Оба способа считают одну и ту же модель: при одинаковых
параметрах получается один и тот же результат.

### Два режима внутри игры

**АВТОМАТ (`MODE=1`).** Самолётом управляет автопилот. Это режим проверки
модели: он показывает, какой должна быть хорошая посадка.

**ПРОГРАММА (`MODE=2`).** В диалоге — внимание к командам и параметрам;
в классической колоде — управление задаётся картами: игрок подбирает
отклонения рулей и тягу по времени.

## Интерактивный диалог

### Запуск

Ядро и оболочка уже записаны в `~/.besm6/2348`, зона `2700(8)`. Вызов:

```bash
cd ~/Yandex.Disk/re-glissade
python3 TOOLS/play.py          # ручная игра: ответы вводятся с клавиатуры
```

Для пакетного прогона с заранее заданными ответами используется
`TOOLS/run_gldial_pty.py` (колода `JOB/GLCALL-2700.B6`, карта `ТЕЛЕ^`).

`WHAT=` — приглашение видеотона, обвязка отвечает на него переводом
строки. Приглашение Pascal — одиночная литера `-`; ответ вводится после
неё. Нельзя запускать `dispak -pdeck` напрямую: задача зависнет.

### Ввод параметров

После заголовка программа спрашивает девять значений:

```

TIP 1..5 :
-
3
> MODE 1 AVTO / 2 PROG :
-
1
> ICTRL 0 BATCH / 1 TERM :
-
0
> NFR SEK :
-
5
> IFLIB 0/1 :
-
0
> TMAX :
-
2400
> RSEED :
-
7351
> SIGW :
-
1.5
> DT0 :
-
0.60
```

| Параметр | Смысл |
|---|---|
| `TIP` | тип самолёта: 1–5 (см. таблицу ниже) |
| `MODE` | 1 — автопилот, 2 — программа пилотирования |
| `ICTRL` | 0 — без контроля; 1 — запросы каждые `NFR` секунд; 2 — контроль Кутта–Мерсона |
| `NFR` | период печати кадра, секунд |
| `IFLIB` | 0 — запасные подпрограммы, 1 — стандартная библиотека |
| `TMAX` | предельное время захода, секунд |
| `RSEED` | исходное число случайных чисел |
| `SIGW` | сила турбулентности, м/с (0 — штиль) |
| `DT0` | начальная тяга, от 0 до 1 |

### Команды

```
PIL: STA STE STO PAR PRN AUTO INS EXIT
MAN: EV+ EV- AI+ AI- RU+ RU- TH+ TH-
```

| Команда | Действие |
|---|---|
| `STA` | пустить непрерывный расчёт |
| `STE` | сделать один шаг (0.1 с) и напечатать кадр |
| `STO` | остановить расчёт |
| `PAR` | заново спросить параметры и вернуть самолёт в исходное состояние |
| `PRN` | напечатать текущий кадр |
| `EXIT` | выйти из программы |
| `INS` | режим инструктора |
| `SEL N` | выбрать упражнение T1…T5 |
| `FRZ` / `UNF` | заморозка / снятие заморозки |
| `INJ N` | ввести отказ с кодом N (1…5) |
| `REC` | начать запись траектории и событий |
| `RPL` | напечатать записанную телеметрию |
| `RST` | очистить буфер записи |
| `HLP` | справка по командам |
| `SCR` | дебрифинг: таблица ошибок по компонентам, балл и зачёт |

Команды вводятся так же, как параметры: после `-`, заглавными буквами
(дописанные пробелы до шести литер не важны).

## Пример 1. Автоматический заход до посадки

Ввод: параметры из примера выше, затем `STA`, а после печати посадки — `EXIT`.
Первый кадр (T=5 с) выглядит так:

```
T= 5.0E+00 TIP=3 DALN= 1.5E+04 VYS= 7.6E+02 Y=-7.4E-01
 VYS PROFILE             | PLAN SVERHU
  800 |                               |    |====|                     *
  700 |.*..                           |    |    |
  600 |    ....                       |    |    |
  500 |        ...                    |    |    |
  400 |           ....                |    |    |
  300 |               ....            |    |    |
  200 |                   ....        |    |    |
  100 |                       ....    |    |    |
    0 |===========================... |    |====|
     15km  10km  5km  0
 GLISS 3 GR |----*----| EGLI=-4.9E+00 M
 KURS LUCH |----*----| Y=-7.4E-01 M
 SKOR= 8.1E+01 VERT=-5.24E+00 ATAKA= 5.8E+00 TYAG= 3.0E+01
```

Как читать кадр:

- `DALN` — дальность до порога, метры; `VYS` — высота; `Y` — отклонение
  от оси полосы;
- левая часть — **профиль**: точки `.` образуют глиссаду, `*` — самолёт,
  линия `=` внизу — земля;
- правая часть — **план сверху**: звёздочка показывает положение
  самолёта относительно оси;
- `GLISS 3 GR` — шкала отклонения от глиссады, `*` — отклонение
  (`EGLI` в метрах);
- `KURS LUCH` — шкала курса, `*` — смещение `Y`;
- `SKOR`, `VERT`, `ATAKA`, `TYAG` — скорость, вертикальная скорость,
  угол атаки и тяга.

Последний кадр перед касанием и оценка:

```
T= 1.9E+02 TIP=3 DALN= 4.0E+00 VYS= 2.2E+00 Y=-1.4E+02
 ...
 GLISS 3 GR |----*----| EGLI= 2.0E+00 M
 KURS LUCH |----*----| Y=-1.4E+02 M
 SKOR= 7.7E+01 VERT=-3.67E+00 ATAKA= 7.3E+00 TYAG= 5.0E+01
OCENKA= 3
PIL: STA STE STO PAR PRN AUTO INS EXIT
MAN: EV+ EV- AI+ AI- RU+ RU- TH+ TH-
-
EXIT
> EXIT
 КОНЕЦ ЗАДАЧИ
```

Это эталонный результат: вертикальная скорость касания −3.67 м/с,
оценка 3 («удовлетворительно»). Касание в 4 метрах от порога.

## Пример 2. Пошаговая игра

Чтобы рассмотреть заход подробно, вместо `STA` вводят `STE` — каждый
раз расчёт продвигается на 0.1 секунды:

```
PIL: STA STE STO PAR PRN AUTO INS EXIT
MAN: EV+ EV- AI+ AI- RU+ RU- TH+ TH-
-
STE
> T= 1.0E-01 TIP=3 DALN= 1.5E+04 VYS= 7.9E+02 Y= 3.2E-06
 ...
 GLISS 3 GR |----*----| EGLI= 3.8E-01 M
 KURS LUCH |----*----| Y= 3.2E-06 M
 SKOR= 7.9E+01 VERT=-5.42E-01 ATAKA= 2.3E-01 TYAG= 3.5E+01
PIL: STA STE STO PAR PRN AUTO INS EXIT
MAN: EV+ EV- AI+ AI- RU+ RU- TH+ TH-
-
STE
> T= 2.0E-01 TIP=3 DALN= 1.5E+04 VYS= 7.9E+02 Y= 3.1E-04
 ...
PIL: STA STE STO PAR PRN AUTO INS EXIT
MAN: EV+ EV- AI+ AI- RU+ RU- TH+ TH-
-
STE
> T= 3.0E-01 TIP=3 DALN= 1.5E+04 VYS= 7.9E+02 Y= 4.0E-04
```

Команда `PRN` повторяет последний кадр, не сдвигая время. `STO`
останавливает непрерывный расчёт, начатый `STA`; `PAR` возвращает
самолёт в исходную точку и позволяет выбрать другой тип или режим.

> В терминальной кодировке разделитель `|` печатается как `?` — это
> тот же символ, примерах выше он записан как `|` для ясности.

## Классическая колода перфокарт

Первая карта данных — пять целых чисел:

1. тип самолёта;
2. режим: 1 — автомат, 2 — программа;
3. контроль точности Кутта–Мерсона: 0 — выключен, больше нуля — включён
   (в диалоге — значение 2; печать `KONTROL ERMAX`);
4. период печати кадра в секундах;
5. библиотека стандартных подпрограмм: 1 — вызовы, 0 — запасные программы.

В рабочей колоде поле 5 равно 1, но подключена запасная программа
`GLNUMR`: в этой среде стандартная библиотека недоступна, и поле не
действует.

Вторая карта — четыре числа: максимальное время, исходное число для
случайных чисел, сила турбулентности в метрах в секунду (ноль — штиль)
и начальная тяга.

В режиме ПРОГРАММА дальше идут карты управления по пять чисел:
время, руль высоты, элероны, руль направления, тяга. Углы даются
в градусах, тяга — от нуля до единицы. Программа линейно интерполирует
между соседними картами. Последняя карта содержит отрицательное время
и завершает таблицу.

В кадрах этой колоды отдельная строка показывает курсовую полосу:
звёздочка отмечает отклонение от глиссады, пять метров на знак.

## Где взять готовые карты

В каталоге `DATA/PROGRAM/` лежат заготовки для четырёх исходных типов (Ан-2 — пока только АВТОМАТ). Они
получены из истории отклонений автопилота и дают рабочий, но не самый
удачный заход. Их назначение — отправная точка для подбора своих карт.

Чтобы попробовать заготовку, нужно подставить её строки после карты
`*execute` в рабочей колоде `JOB/GLISSADA.B6` вместо текущих карт данных.

## Полезные подсказки

- Если самолёт садится раньше порога — увеличьте тягу в первой половине
  захода или чуть уменьшите руль высоты.
- Если самолёт долго летит над полосой — уменьшите тягу.
- Если касание жёсткое — начните выравнивание раньше, за 25–40 метров
  до земли, и увеличите руль высоты на последних картах.
- Если самолёт раскачивается по высоте — сгладьте карты, не меняйте
  руль высоты резко между соседними моментами времени.
- В диалоге удобно сначала просмотреть заход по шагам (`STE`), а затем
  пустить его целиком (`STA`) уже с понятной вам картиной.
- `RSEED` задаёт турбулентность: при одном и том же семени заход
  воспроизводится точно. Эталонный прогон использует `RSEED=7351`,
  `SIGW=1.5`, `DT0=0.60`.

Скрипт делает резервную копию, записывает ядро и оболочку в зону
