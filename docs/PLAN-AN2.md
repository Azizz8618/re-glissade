### 1.2 `GLAUTO.FTN`
- строка 15: `GO TO (100,200,300,400),KTIP` → `(100,200,300,400,500)`;
- **после ветки 400 обязательно `GO TO 150`** — иначе Ан-24 начнёт
  исполнять коэффициенты Ан-2 (тихий регресс phase3);
- ветка `500` (стартовые коэффициенты, подлежат подбору):
  `GE=0.20` (0.08 при SIGW>0), `VYC=-0.05241*X(1)-GE*EGLI`,
  порог `HCR+4.` (6.5 м абсолютной высоты, по РЛЭ 6–7 м),
  `VYC=-0.5`, `DE=-0.04*(X(2)-VYC)-0.5*X(10)`, `GO TO 150`.
- ветки 100–400 **не трогать ни одного символа**.

### 1.3 `GLOUT.FTN`, `GLPROIZ.FTN` — НЕ менять
`GLOUT:82` — это индекс оценки K=1..4, не KTIP. `MOTOR` различает только
ETYPE=1/2; для Ан-2 ETYPE=2 с THMAX=13000 даёт при DTZ=0.35 тягу 4,55 кН
(требуется 4,53 кН) — сходится.

## 4. Этапы и критерии

0. База: сохранить контрольные суммы чистого прогона; SRC — истина.
1. Правки SRC. Критерий: CHECK-DECK проходит; в diff только 2 `GO TO`,
   ветка 50, `GO TO 150`, ветка 500; типы 1–4 побайтово неизменны.
2. Данные GLIS1-T5.DAT. Критерий: карта 1 — 25 символов, карта 2 — 32.
3. Сборка. Критерий: в колоде `GO TO (…,50)`, `GO TO (…,500)`, `5H AN-2`.
4. Прогон АВТОМАТ и подбор ветки 500. Критерий: `TIP SAMOLETA: AN-2`,
   `OCENKA=1..3`, касание за порогом, `|Vy|≤2.5`, SKO≤10 м, ноль ошибок
   201/205, завершение 411. Отчёт — `docs/analysis/an2-nastroyka.md`.
5. ПРОГРАММА: снять историю RV/TYAG из прогона, построить GLIS2-T5.DAT.
6. Документы: PAKET.TXT, MODEL.TXT, README.md, KAK-IGRAT.md, STATE.md,
   PLAN.md — везде 4 типа → 5.
7. Регрессия: 5 типов × 2 режима; типы 1–4 сверить с phase3-таблицей
   побайтово. Коммиты в оба репозитория.

## 6. Риски

1. Рассинхрон колод — главный: регенерация заменит старый GLAUTO для
   всех типов; контрольные суммы STATE.md перестанут совпадать (ожидаемо).
2. Правка веток 100–400 снимает «отлично» у Ту-104 — обязателен
   `GO TO 150` после ветки 400.
3. Коэффициенты ветки 500 — стартовые; реальное выравнивание 6–7 м
   против 30–40 м ⇒ возможно поднять порог до HCR+10…15 или сместить
   глиссаду. Опыт phase3: GE=0.50 при турбулентности даёт раскачку.
4. TMAX=1200 безопасен (469 с в штиль + запас).
5. ETYPE=2 аппроксимирует поршневой винт; множитель 1.6 завышает КПД,
   компенсировано THMAX=13000; проверить `TYAG=` в печати.
6. Холлерит только латиницей (`5H AN-2`), счётчик точно равен числу символов.
