# МОДЕЛЬ ОТКАЗОВ ТРЕНАЖЁРА

Дата: 18 ноября 2026 года. Реализована в `SRC/GLFAULT.FTN`, вводится
командой инструктора `INJ` с аргументом-кодом.

## Коды

| Код | Отказ | Эффект в модели |
|---|---|---|
| 1 | потеря тяги | `TH = TH·0,30` в подпрограмме `MOTOR` |
| 2 | заклинивание руля высоты | `U(1)` замораживается на значении момента ввода |
| 3 | заклинивание элеронов | `U(2)` замораживается |
| 4 | заклинивание руля направления | `U(3)` замораживается |
| 5 | сдвиг ветра | `WGX += 2,0`, `WGY += 3,0` м/с |

Код 0 снимает отказ (`GLFCLR` вызывается также при каждом `INIT`, то есть
при смене упражнения через `SEL` и при `PAR`).

## Реализация

- `COMMON /FAULT/ IFALT,TINJ,DEJ,DAJ,DRJ` — код, время ввода и
  зафиксированные органы управления.
- `GLFINJ(K,U)` — процедура для Pascal, запоминает код и текущие `U(1..3)`;
  `GLFCLR` — сброс.
- `FLTU(U)` вызывается в `PROIZV` перед расчётом моментных членов;
  `FLTTH(TH)` — в `MOTOR`; `FLTW(WGX,WGY,WGZ)` — в `TURB`.
- Все имена ≤6 литер, как требует ФОРЭКС.

## Проверка

Прогон с отказом 1 (Ту-104, штиль): `FAULT=1 INJECTED`, 14/14 ответов
PASRED, штатное завершение, `OCENKA=2` — траектория отличается от
безотказной. Регрессия: исторические сценарии 10/10, упражнения 4/5
(T2 — ранее зафиксированный GAP).

## Ограничение

Отказы задаются фиксированными кодами и не имеют настраиваемой
интенсивности. Модель не воспроизводит отказ двигателя как физический
процесс (помпаж, выбег) — только снижение тяги. Для учебных сценариев
этого достаточно; для полноценного тренажёра модель отказов будет
расширяться отдельными этапами.
