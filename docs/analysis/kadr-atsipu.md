# Кадр АЦПУ тренажёра «Глиссада-6»

Дата: 19 ноября 2026 года. Описание соответствует текущей сборке
(PERSO зона 2700(8), `PRFRM` в `SRC/GLDIAL.PAS`).

## 1. Геометрия кадра

Кадр рассчитан на терминал 15ИЭ: 80 знаков в ряду, 25 рядов. Фактически
печатается 22 строки: строка заголовка, строка подписей графов, 13 рядов
профиля, строка масштаба и пять информационных строк. Разделитель между
графами и столбцами — `+`. Числа выводятся процедурой `PRNUM` в натуральном
виде с двумя знаками после запятой, фиксированная ширина поля 7 знаков.

## 3. Левый граф — профиль высоты

- Горизонталь: удаление до порога, 15 км в левой позиции, 0 в правой,
  30 позиций по 500 м.
- Вертикаль: высота над плоскостью порога, 13 рядов от 1200 до 0 м,
  шаг 100 м.
- `T` — рельеф местности. Высота земли для каждой позиции считается
  подпрограммой `ZEM` в `SRC/GLRELF.FTN` по профилю `/RELF/`, профили
  заданы по типам самолётов из OSINT-исследований.
- `.` — глиссада 3° (`0,05241 · удаление`).
- `*` — самолёт на профиле.
- `=` —земля на нулевой высоте.

Приоритет вывода: самолёт, рельеф, глиссада, земля. Поэтому при совпадении
символов виден самый «важный»: сначала `*`, затем `T`.

## 4. Правый граф — план сверху

Полоса обозначена как `+====+`. Звёздочка показывает положение самолёта
по поперечной координате: `IB = 21 + TRUNC(X(12)/5)`, то есть центр — ось
полосы, деление 5 м, диапазон 1…41 позиция. В приведённом кадре `Y=−2,71`
— самолёт почти на оси, звёздочка в центре.

Звёздочка на шкалах `+----*----+` в нижних строках — неподвижная метка
нуля: отклонение глиссады или курса; текущее значение выводится числом
справа.

## 5. Нижние строки — два столбца

Левый столбец (38 знаков):

| Поле | Смысл |
|---|---|
| `EGLI` | отклонение от глиссады, м (`X(13)+0,05241·X(11)`) |
| `Y` | поперечное отклонение от оси полосы, м |
| `SKOR` | воздушная скорость, м/с |
| `VERT` | вертикальная скорость, м/с |
| `ATAKA` | угол атаки, градусы |
| `TYAG` | тяга в процентах от максимальной |
| `KONF F… G… S…` | конфигурация: закрылки, шасси, спойлеры |

Правый столбец (38 знаков):

| Поле | Смысл |
|---|---|
| `ZEMLYA` | высота земли под самолётом, м |
| `PROSVET` | текущий просвет: высота минус земля, м |
| `MIN` | минимальный просвет за прогон, м |
| `TOPLIVO` | текущий запас топлива, кг; метка `MALO` при достижении порога |
| `REZERV` | посадочный резерв с множителем задания, кг |

`EGLI` и просвет — **разные величины**: первое нужно автопилоту и накоплению
СКО, второе — предупреждению об опасном сближении. Подмена одного другим
испортит эталонные траектории.

## 6. Команды, влияющие на кадр

| Команда | Действие |
|---|---|
| `FLP 0/1/2` | убраны / взлётные / посадочные закрылки |
| `GER 0/1` | шасси убрано / выпущено |
| `SPL 0/1` | спойлеры убраны / выпущены |
| `FUL <кг>` | добавить топливо к запасу задания |
| `RES <множитель>` | изменить посадочный резерв |
| `EPS <допуск>`, `PFL <порог>` | параметры адаптивного контроля |
| `DTC <с>` | шаг контроля вручную |

Все команды вводятся в режиме инструктора `INS`, латиницей, не более
шести литер, без буквы `Y`.
