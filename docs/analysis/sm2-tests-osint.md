# ПОИСК ТЕСТОВ И ДИАГНОСТИК СМ-2 В ИНТЕРНЕТЕ

Дата: 18 ноября 2026 года. Часть подготовки плана модификации `hp2100` → СМ-2.

## 1. Что искалось

Запросы через DuckDuckGo (2026-11-18):

- «тест СМ-2М диагностика тестовая программа»;
- «эмулятор СМ-2М СМ ЭВМ симулятор»;
- «М-6000 СМ-2 тест контрольная программа тестов»;
- «"СМ-2М" "тест" ПСЕ архив»;
- «"М-6000" "тест" эмулятор ПСЕ».

## 2. Результат

**Готовых тестовых/диагностических программ именно для СМ-2 или СМ-2М
в открытом интернете не найдено.** Поисковая выдача состояла из:

- автомобильных диагностических адаптеров Scanmatik SM2 / SM2 Pro
  (полное совпадение аббревиатуры, другой контекст);
- эмулятора Sega Model 1/2 (`github.com/dmanlfc/sm2-emu`);
- общих статей про эмуляторы советских систем (Habr, `habr.com/ru/articles/592015/`);
- учебного курса «Аппаратное обеспечение вычислительных систем» ИТМО
  (`evm.goodbroch.ru`) с эмуляторами **базовой ЭВМ**.

Отдельно проверен указатель computer-museum.ru `histussr/sm0.htm`: там
перечислены обзоры, статья Савватеева по	CМ-2М, архив статьи про СМ-3/СМ-4,
но разделов с тестами или дисками СМ-2 нет.

## 3. Учебная «базовая ЭВМ» ИТМО — не подходит как тест СМ-2

`evm.goodbroch.ru` предлагает четыре эмулятора и 8 лабораторных работ, но
система команд учебной БЭВМ другая:

| | Учебная БЭВМ | СМ-2М |
|---|---|---|
| Мнемоники | `AND`, `JSR`, `MOV`, `ADD`, `ADC`, `SUB`, `BCS`, `BPL`, `BMI`, `BEQ`, `BR`, `ISZ`, `CLA`, `CLC`, `CMA`, `CMC`, `ROL`, `ROR`, `INC`, `DEC`, `HLT`, `NOP`, `EI`, `DI` | `ADA`, `ADB`, `LDA`, `LDB`, `STA`, `STB`, `CPA`, `CPB`, `JMP`, `JSB`, `AND`, `XOR`, `IOR`, `ISZ`, `FAD`… |
| Коды | 4 бита КОП, 11 бит адреса, 2048 слов | 4 бита КОП в разрядах 1–4, адресация 15/17 бит |
| Регистры | один аккумулятор A, флаг C | РА, РБ, РР, РП, РИ1/РИ2, РБ1/РБ2, РВГ/РНГ |

Сходство только в идейном подходе (однословные команды, косвенная
адресация, «приращение и пропуск» `ISZ`). Использовать как готовый тест
для СМ-2 нельзя.

## 4. Что реально можно использовать

1. **HP 24396 Stand-Alone Diagnostics** — поставляется с `simh/HP2100`
   (`HP2100/hp2100_diag.txt`, прогон 63+ тестов, 0 FAIL). Это эталон для
   *подмножества HP-совместимых команд* — можно гнать один и тот же
   диагностический код на `hp2100` и на будущем `SM2` в режиме
   HP-совместимости и сравнивать трассы/результаты.
2. **Таблица кодов СМ-2М из статьи Савватеева** — источник для
   собственных «золотых» тестов: по каждой из 14 однословных, 17 двухсловных,
   регистровых и дополнительных команд можно собрать минимальную программу
   с ожидаемым результатом (арифметика, флажки РР/РП, пропуск РНК на 2,
   автоиндексация, float, TAS, массивы).
3. **Книга Клиорина/Кадулина/Смолкина (1989)** — источник наставлений по
   ОС АСПО/ДОС-РВ; при создании тестов пригодится как описание
   ожидаемой работы системы.
4. **Тесты К-71 в смежных проектах** (`re-dispak/testdks/test_k71.txt`,
   `test_sis_k71.txt`) — не тесты СМ-2, а тесты КАДОПАМ/ДКС; пригодны
   для проверки связки ЦВС↔ПВС после того, как эмулятор СМ-2 будет готов.

## 5. Предлагаемая стратегия тестирования

| Уровень | Что делаем | Источник эталона |
|---|---|---|
| Команда | нормально: одна команда → ожидаемые РА/РБ/РР/РП/РНК | статья Савватеева, таблица кодов |
| Группа команд | арифметика, сдвиги, пропуски, float | ручной расчёт + `hp2100` для HP-подмножества |
| Память | Z/текущая страница, косвенная, индекс/автоиндекс, РБ1/РБ2, РВГ/РНГ | описание СМ-2М |
| Прерывания | векторы 4/5/6 + код выборки, УСП, STF/CLF | описание СМ-2М |
| Ввод-вывод | OTA/OTB/LIA/LIB/MIA/MIB через «Сопряжение 2К» | описание СВВ/РИМ |
| Система | загрузка АСПО/ДОС-РВ, если образы будут найдены | GAP — образов нет |

## 6. GAP

- Образов ПО и тестовых программ СМ-2/СМ-2М в internet нет.
- Нет эмулятора СМ-2, с которым можно было бы сверить результаты.
- С чтением архивов ПСЕ (псевдо-СЭВМ) работа не ведётся — источник не найден.

### 7.2 Найденный профильный форум

**`ruecm.forum2x2.ru` («RUЭВМ»)** — форум, посвящённый ЭВМ и электронике.
Индексируемые разделы:

- `f153` — «Линия АСВТ. СМ-1, СМ-2, СМ-1М, СМ-2М, СМ-1634, СМ-50/60,
  СМ-1210, ПС-1001 и т. д.» (обновлялся 14.08.2026);
- `f150` — «СМ ЭВМ»;
- `f20` — «Эмуляторы отечественных ЭВМ и ПЭВМ»;
- `t1015` — «СМ ЭВМ. Статьи, заметки, очерки, разное…», в описании
  упомянуты «Системы контроля и диагностики мини- и микроЭВМ».

Это наиболее ценный адрес для дальнейшего поиска, но **сам сайт из текущей
среды недоступен**: прямые запросы к `f153` и `t1015` завершаются по
таймауту, прокси `r.jina.ai` возвращает 451. Удалось прочитать только
сниппеты поисковика. Признаков выложенных тестов СМ-2 в сниппетах нет.

### 7.3 Вывод

Форумный OSINT подтвердил: сообщество по СМ ЭВМ существует и имеет
отдельный раздел по линии АСВТ/СМ-2, но готовые тесты СМ-2 через
индексируемые сниппеты не обнаружены. Для прямого доступа к вложениям
форума нужен работающий канал к `ruecm.forum2x2.ru` (браузер/другая сеть).
