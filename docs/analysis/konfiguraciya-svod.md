## 2. Ключевая проблема базовых коэффициентов

Текущие значения в `GLTTX.FTN` не являются «чистым крылом» у всех типов:

- **МиГ-15**: `CLMX=1,46` совпадает с книжным максимумом **при закрылках 55°**;
- **Ан-2**: `CL0=0,72`, `CLMX=1,95` уже описывают посадочную конфигурацию при «чистом» `CD0=0,027`;
- **Ту-104**: `CLMX=1,35` — чистое крыло, но площадь крыла в модели 344,6 м² против 174–183 м² по документу.

Поэтому приращения надо задавать **относительно текущей базы**, а не от физического чистого крыла. Для МиГ-15 и Ан-2 приращение `CLmax` при переходе в посадочную конфигурацию обнуляется, чтобы не было двойного счёта. Это честно фиксируется как GAP: физическая интерпретация базы различается по типам.

## 3. Рекомендуемые приращения от текущей базы

Конфигурации: `0` — текущая (база, как в эталонных прогонах), `1` — взлётная, `2` — посадочная.

| МиГ-15 | 2 (55°) | +0,55 | 0 | +0,045 | +0,06 | −0,3 |

Шасси добавляет `ΔCD0≈+0,010` для МиГ-15/Ил-28/Ту-104/Ан-24; у Ан-2 шасси неубирающееся и вклада не даёт.

Все числа, кроме `ΔCLmax` Ан-24 и данных Радченко по Ан-2, — оценки по графикам и скоростям срыва. Помечено `[О]` в источниках.

## 4. Требование к реализации

1. Конфигурация — состояние полёта, меняется командами во время захода.
2. На каждом шаге эффективные коэффициенты пересчитываются из базы плюс приращения — без накопления при повторных переключениях.
3. Конфигурация по умолчанию `0` сохраняет текущие коэффициенты и регрессию 10/10, 5/5, md5.
4. В кадре выводится текущая конфигурация.

## 5. GAP

- Нет документированных поляр с коэффициентами для МиГ-15 и Ил-28; приращения сняты с графиков качества и скоростей срыва.
- Площадь крыла Ту-104 в модели расходится с документом; новые коэффициенты потребуют перекалибровки ветви `GLAUTO`.
- Моментные приращения оценочные; знак у Ан-24 и Ан-2 различен.
- Физическая интерпретация базы различается по типам (см. §2).
