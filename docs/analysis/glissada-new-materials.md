### 1.2 Интерфейсные метки — совпадают с `re-mrv`

В листинге встречаются те же метки, что в расшифрованном модуле **WCD**
(`/home/azizz/Yandex.Disk/re-mrv/docs/wcd/`, выдача на СМ-2):

| Метка в тесте | Назначение |
|---|---|
| `OUT FLD1`, `OUT FLD2`, `OUT FLD3` | выходные поля (адреса `LC 1000/1200/1000`) |
| `CNT ПС1` … `CNT ПС4` | счётчики подсистем |
| `CONT,NUM PS` | номер подсистемы |
| `CONT,A PROG` | адрес программы |
| `CONT,A TABL` | адрес таблицы |
| `CONT,LENG` | длина блока (слов) |
| `CONT,A MIMV` | номер блока (переданный) |
| `N МАШ.-ДОП.КОД` | номер машины и дополнительный код |
| `EVA1`, `EVA2` | признаки конца/ошибки |
| `ЧИСЛО ОШИБ. ОПЕРАТОРОВ` | счётчик ошибок |

Это означает, что новый PDF — **реальный тест интерфейса БЭСМ-6 ↔ СМ-2**
из того же комплекта СПО К-71, из которого сделан `re-mrv`. В репозиториях
`re-mrv`, `re-dispak`, `simh` цифровой копии этого теста нет.

### 1.3 Структура листинга

OCR показывает несколько подпрограмм с собственными таблицами структуры
(ЗАГОЛОВОК / ОБОЗНАЧЕНИЯ / ИДЕНТИФИКАТОРЫ / КОМАНДЫ / ГРУППА /
КОНСТАНТЫ / ДАННЫЕ / РАССЫЛКИ / ТАБЛИЦА ССЫЛОК):

| Метки | Содержание |
|---|---|
| `TST00720` … `TST01940` | основная программа; таблицы `TBL FLD`, `TBL CNT`; печать `TEXTL` с текстом «ПЕРЕДАЧА НЕ НАСТУПИЛА», «ЧИСЛО ОШИБ»; `CNT ПС1…4`, `OUT FLD1…3`; `END.` |
| `TST01950` … `TST02560` | подпрограмма «ПЕРЕКОДИРОВКА ДАННОЙ ПС»; регистры `R0…R16`, значения `INT 0…16`, счётчики `CNUM`, `ABL`, `NPS`; проверка `ВРЕМЯ ПЕРЕДАЧИ НЕ НАСТУПИЛО` |
| `TST02540` … | variant подпрограммы с `CNT MCL`, модификация таблицы счётчиков |
| `TST02770` … | хвост/таблицы ссылок |

Встречаются также коды `KK = 1:37` (интервал передачи), ` STL 9` (адрес
описателя блока), `ATT 10` (N МАШ.-ДОП.КОД), `ATX 11`, `VZM ALL EVA1`.

## 2. `Блок_БИД_описание (1).pdf` — документ К-71

Файл побайтово совпадает с уже имеющимся `Блок_БИД_описание.pdf`
(md5 `b985fd91…`), но ранее не был распознан. 4 страницы, OCR выполнен.

Титул: **«СИСТЕМА КТ. БЛОК БИД. Техническое описание К71.07.00.00 ТО»**.

- **Назначение:** подключение дисплеев к БЭСМ-6 для диалогового режима.
  Стандартная БЭСМ-6 не имеет интерфейса подключения дисплеев; блок БИД
  (блок интерфейсный дисплейный) подключает до **8 дисплеев 15ИЭ-00-013**
  к телеграфным каналам ЭВМ.
- **Характеристики:** 8 дисплеев, скорость **200 Гц**, последовательная
  телеграфная посылка, длина линии до **150 м**, синхронизация через
  **19-й разряд главного регистра посылок БЭСМ-6**.
- **Состав:** ячейки `УТ1` (приёмник), `УТ2` (передатчик), `БУТ` (синхронизация
  дисплея с работой ЭВМ). Размещение: две стойки БЭСМ-6 — `КВУ` (УТ1, УТ2)
  и `БРУС` (БУТ).
- **Принцип:** в стандартной БЭСМ-6 для телетайпов T-63 используются блоки
  сопряжения ВСТ и УСТ (по 8 каналов каждый). С БИД согласование выполняют
  УТ1/УТ2. Каналы приёма и выдачи в ОС «САСПАХ» имеют один и тот же номер,
  поэтому связи входа УТ1 и выхода УТ2 разрываются и выводятся на внешний
  разъём 9116 стойки КВУ.
- **Синхронизация:** внешний генератор 2,0 кГц в БУТ, счётчик-делитель на 10,
  синхроимпульсы 250 Гц через микросхемы КТ55ЛА6 и согласующие сопротивления
  82 Ом идут по коаксиальным линиям к дисплеям (используются при выдаче
  информации в БЭСМ-6).

**Значение для проекта:** это документ из той же серии, что и
`К71.05.01.00 ТО` (КАДОПАМ) — `К71.07.00.00 ТО` (БИД). Он подтверждает,
что уровень ТОР К-71 builder-ски realizovan как аппаратный интерфейс
дисплеев на базе БЭСМ-6, и даёт конкретные параметры канала.
