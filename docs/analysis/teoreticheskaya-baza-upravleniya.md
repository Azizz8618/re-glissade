## 2. Главные выводы

### 2.1 Наш закон управления уже имеет трёхконтурную структуру

Тождество из `GLAUTO.FTN`:

```
VY − VYC = ĖGLI + GE·EGLI
```

показывает, что `PGE` задаёт частоту излома цепочки опережения, `PKV`
усиливает темп отклонения (демпфирует фугоид), а `PKD` гасит
короткопериодический тангаж. Это совпадает с классической схемой
`δe = −kw·w − kq·q − kθ·θ` (MIT 16.333, лекция 13).

**Практический вывод:** усиления следует настраивать в порядке
`PKD → PKV → PGE` (внутренний контур наружу), а не случайным перебором,
как делалось до сих пор. Критерий — запасы по амплитуде ≥6 дБ и по фазе
≥45°, демпфирование фугоида ζ≥0,55 и короткопериодики ζ≥0,4
(NASA Kaminer). Числа должны быть получены линейзацией нашей модели,
а не скопированы из литературы.

### 2.2 Адаптивный шаг контроля — не адаптивный шаг интегрирования

Период пересчёта регулятора определяется полосой пропускания контура:
`T = 2π/(N·ω_B)` при `N = 6…10` (Åström–Wittenmark), практическое правило
10–20 точек на период. Оценка Мерсона пригодна лишь как косвенный
индикатор.

**Практический вывод для `ICTRL=4`:** сузить диапазон `DTCTRL` примерно до
0,1…0,2–0,3 с (сейчас 0,02…0,5), сделать уменьшение шага быстрее роста
(0,6…0,7 против 1,1…1,2) и откалибровать `EPSKM` по **абсолютной** ошибке
`KUTMER`, а не по относительному допуску режима 3. `DTMIN=0,02` —
«фантомная» граница: при `DTCTRL < H = 0,1` управление всё равно
пересчитывается только раз на шаг интегрирования.

### 2.3 Защита от сваливания обязана ограничивать команду, а не результат

Аддитивная вычитка из уже посчитанного `DE` опаздывает и не ограничивает
полномочия расходящегося контура. Рабочая схема — нелинейный ограничитель
команды с гистерезисом, порогом `min(0,85·TALFS, G·n_z,max/(q·S·CLA))`,
снятием на 0,75·TALFS и упреждением по `α̇`.

**Критическая деталь нашей модели:** `ALFA` в `/VYVOD/` уже в **градусах**
(`GLPROIZ.FTN`), а `TALFS` в радианах. Поэтому прежняя попытка ограничения
угла атаки срабатывала не там, где надо — это объясняет её неудачу.

### 2.4 Отечественная традиция подтверждает структуру, но не даёт чисел

Найдены закон Петунина `δв = kϑ(ϑ−ϑзад) + kωz·ωz`, изодромный закон
(МГТУ ГА), критерии Мерсона с уменьшением при `|R| > ε` и увеличением при
`32|R| < ε`, зависимость усилений от удаления до порога (Труды МАИ, 2020).
Подлинный текст `АД01` в сети не найден; К-71 — морской тренажёр и не
содержит применимых законов управления.

Два проверяемых наблюдения по нашему коду:

1. `/APGAIN/` не зависит от удаления до порога — возможный резерв точности;
2. шестая стадия `K6` в `KMERR` объявлена, но не используется.

Оба требуют отдельного этапа с перекалибровкой и повторной побайтовой
сверкой эталонов.

## 3. Ранжированные шаги

| Шаг | Риск | Комментарий |
|---|---|---|
| Перевести `ALFA` в радианы в любом будущем канале защиты | низкий | исправляет скрытую ошибку размерности |
| Сузить `DTCTRL` до 0,1…0,3 и сделать адаптацию асимметричной | низкий | режим 4 opt-in, регрессия не затронута |
| Линеаризовать модель и посчитать `PKD/PKV/PGE` по запасам 6 дБ/45° | средний | потребует перекалибровки 10 сценариев |
| Ввести напорную коррекцию по Kaminer | средний | меняет траектории |
| Зависимость усилений от удаления до порога | высокий | меняет структуру `GLAUTO` |
| Перепроектировать расходящийся контур высоты для T2 | высокий | сейчас T2 закрыт ручным пилотом |

## 4. Честные GAP

- Конкретные числа усилений из литературы не переносятся на нашу модель —
  нужна линеаризация и перекалибровка.
- Текст `АД01` недоступен;наш `GLKMA.FTN` — реконструкция по каталогу.
- Модель сваливания упрощена (кусочно-линейный `CL`), пороги g-limiting
  не калиброваны.
- Все рекомендации поaic защите — рабочая гипотеза без прогона на эмуляторе.
