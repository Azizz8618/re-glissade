Дата составления: 19 ноября 2026 года.

Статус: разведывательный отчёт. Основой стали две локальные книги, которыеirmed являются первичными источниками: техническое описание МиГ-15бис под редакцией Л. С. Соголова, книга первая, и наглядное пособие к инструкции летчику по эксплуатации и пилотированию самолётов Ил-28 и Ил-28У 1972 года. Обе книги лежат в папке `/home/azizz/Рабочий стол/Глиссада-6/`. Веб-источники использованы только для подтверждения и для общих методов.

Метод извлечения. Прямое извлечение текста командой `pdftotext` дало только символы переводов страниц: оба файла полностью отсканированы. Текст получен через `pdftoppm` с последующим распознаванием `tesseract` с русским языком. Результаты сохранены в файлах `/tmp/.private/azizz/opencode/ocr/mig15/txt/pg-NN.txt` и `/tmp/.private/azizz/opencode/il28book-ocr.txt`. Числа с графиков сняты визуально по увеличенным фрагментам страниц. Пометки: [Д] — прямо указано в документе, [Р] — расчёт по документным числам, [Г] — прочитано с графика, [О] — оценка.

Важное расхождение с исходной гипотезой. Гипотеза предполагала посадочные закрылки около 20–25 градусов у МиГ-15 и около 25–30 градусов у Ил-28. Первоисточники дают другие цифры: у МиГ-15 посадочный угол 55 градусов, взлётный 20 градусов; у Ил-28 посадочный 50 градусов, взлётный 20 градусов. Угол 20 градусов у обоих типов — взлётное положение, а не посадочное. Ниже приведены приращения для обоих положений, основным считается посадочное.

### 1.6. База нашей модели

В `SRC/GLTTX.FTN` для МиГ-15 записаны `CL0=0,15`, `CLA=5,7`, `CLMX=1,46`, `CD0=0,025`, `CM0=0,025`; для Ил-28 — `CL0=0,20`, `CLA=4,8`, `CLMX=1,57`, `CD0=0,034`, `CM0=0,02`. Файл `SRC/GLINITD.FTN` копирует эти числа в `/SOST/`. Угол срыва `TALFS` вычисляется как `(CLMX-CL0)/CLA`, поэтому приращения к `CL0` и `CLMX` автоматически сдвигают порог сваливания.

Ключевое наблюдение: значение `CLMX=1,46` в нашей модели для МиГ-15 совпадает с числом из книги Соголова для закрылков 55 градусов, то есть уже включает механизацию. То же верно для Ил-28: значение 1,57 соответствует 50 градусам. Прямое прибавление прироста `CLMX` даст двойной счёт.

### 2.5. Отдельно шасси

Книга Соголова даёт поляры отдельно для убранного и выпущенного шасси при нулевом и 20 градусах закрылков, но без подписей числовых значений на осях в тексте; снять вклад шасси можно только приблизительно по рисунку 51: при нулевых закрылках минимальное сопротивление растёт примерно с 0,015 до 0,030, то есть на 0,015 [Г]. Для МиГ-15 это единственная количественная оценка отдельного вклада шасси. Влияние шасси на подъёмную силу и момент пренебрежимо мало [О]. Для Ил-28 раздельного вклада шасси нет.

### 2.7. Оговорка для реализации

Поскольку базовый `CLMX` уже равен максимуму при выпущенных закрылках, перед вводом перехода конфигурации нужно либо обнулить приращение `CLMX`, либо снизить базу примерно до 1,20 у МиГ-15 и 1,24 у Ил-28 и затем добавлять прирост. Иначе порог `TALFS` и посадочная скорость окажутся завышенными. Остальные приращения можно вводить аддитивно, но смена конфигурации изменит балансировку по тангажу и потребует пересмотра триммирования в ветках автопилота.

## 3. Пробелы

1. В книге по Ил-28 нет поляр и таблиц коэффициентов подъёмной силы, сопротивления и момента. Все приращения `CL0`, `CD0` и `CM0` для Ил-28 остаются оценками. Для точных значений нужен оригинальный отчёт по аэродинамическим характеристикам или РЛЭ с полярами.

2. Раздельный вклад шасси и закрылков в сопротивление у МиГ-15 снят с графика приблизительно; у Ил-28 он не выделен вообще, так как книжные скорости срыва для выпущенных конфигураций включают шасси.

3. Нет документированного приращения момента от закрылков в числовом виде. Для МиГ-15 оно прочитано с графика, для Ил-28 знак не подтверждён.

4. Нет прямых данных о влиянии закрылков на наклон кривой подъёмной силы. Величины `CLA` оценены по виду графиков.

5. Нет сведений о тормозных щитках на Ил-28, включая модификации.

6. Площадь тормозных щитков МиГ-15 в книге указана дважды: 0,5 квадратного метра для лётных данных и 0,8 квадратного метра для самолётов выпуска 1952 года. Веб-источник даёт 0,48 квадратного метра для прототипа. Для модели 1952 года следует брать 0,8.

7. Числа с графиков прочитаны по изображениям с ограниченной точностью; погрешность для коэффициентов момента может достигать 0,02–0,03.

8. Часть строк распознавания в обоих файлах испорчена двухколоночной вёрсткой; все цитаты сверены по изображениям страниц.

## Главный вывод

Локальные книги подтвердили главное: посадочные закрылки 55 градусов у МиГ-15 и 50 градусов у Ил-28, а 20 градусов — взлётное положение. Из книги Соголова получены прямые числа: коэффициент подъёмной силы 1,46 при 55 градусах, качество 14,6 в чистой конфигурации и 6,5 с закрылками и шасси, минимальное сопротивление 0,0150, коэффициент сопротивления тормозных щитков около 0,0225 для площади 0,5 квадратного метра. Из наглядного пособия по Ил-28 получены скорости срыва 225, 230, 205 и 200 км/ч для четырёх конфигураций, что даёт приросты максимума 0,25 и 0,33. Обе книги извлечены успешно, хотя прямое извлечение текста не работало и потребовалось распознавание сканов. Главная проблема реализации прежняя: базовый `CLMX=1,46` уже совпадает с книжным максимумом при 55 градусах, поэтому приращение к нему нужно обнулить или снизить базу, чтобы не было двойного счёта.
