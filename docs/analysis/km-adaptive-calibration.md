# КАЛИБРОВКА АДАПТИВНОГО ШАГА

Дата: 18 ноября 2026 года.

## 1. Что реализовано

- `SRC/GLKMA.FTN`: `/KMCTL/` (EPS, HMIN, HMAX, SAFETY, MAXTRY, EXPN,
  PFLOOR), оценка Мерсона с **относительной нормой и порогом `PFLOOR=1.0`**
  (по образцу `DE13R` НИВЦ МГУ), настройка шага
  `H·SAFETY·(EPS/ERR)^EXPN`.
- `SRC/GLDIAL.PAS`, режим `ICTRL=3`: **шаг управления отделён от шага
  интегрирования** — автопилот и ручные органы обновляются каждые 0,1 с
  (`DTCTRL`), даже когда `DTSH` вырос до 0,3–0,8 с. Между обновлениями
  используется `UHOLD`.
- Команды инструктора `EPS <допуск>` и `PFL <порог>`; печать `DTSH` в
  дебрифинге.

Режим Егорова (`ICTRL=4`) **не добавлялся** — оставлена наша модель
Мерсона по решению пользователя.

## 3. Регрессия

- 10 исторических сценариев — без изменений;
- 5 упражнений — 4/5 (T2 — прежний GAP);
- `replay.py verify` — md5 `ed36267c…` без изменений.

Режим включается только `ICTRL=3`, поэтому эталонные прогоны не задеты.

## 4. Ограничения

- Калибровка сделана на штиле; при `SIGW>0` шаг также влияет на дискретизацию
  фильтра Орнштейна–Уленбека (дрейф интегрируется явным Эйлером, `h/TAU`
  до 0,7).
- `HMAX=1.0` — шаг может вырасти до 0,76 с; для упражнений с резкими
  вводными это может быть слишком крупно.
- Подлинный алгоритм `АД01` всё ещё не дизассемблирован (модуль в архиве
  `LIBR1` диска 2248).
