# ЭТАЛОННЫЕ ПОСАДКИ НА РЕАЛЬНЫХ ТТХ В РАЗЛИЧНОЙ ПОГОДЕ

Дата: 18 ноября 2026 года. Все числа ТТХ взяты из `SRC/GLTTX.FTN`
(171 значение в `/TTXDAT/`, см. `ttx-audit.md`).

## 1. Что считается эталонной посадкой

- вертикальная скорость касания `|VERT| <= 4.0 м/с` (оценка не ниже 3);
- касание **за** порогом полосы (`TCH >= 0`);
- нет аварийного сообщения «KASANIE DO POROGA»;
- расчёт завершается штатно (`КОНЕЦ ЗАДАЧИ`, `*74`).

## 2. Условия прогона

| Режим `MODE` | 1 (автопилот) |

| `TMAX` | 2400 с |
| `RSEED` | 7351 |
| `DT0` | 0.60 |
| `SIGW` | 0 / 0.3 / 0.5 / 1.0 / 1.5 м/с |

Шаг интегрирования 0.1 с, РК-4, турбулентность — фильтр
Орнштейна–Уленбека (`GLNUMR.FTN`).

## 3. Инструменты

Параметры автопилота — по seven чисел на тип:
`[GE, GEW, OFF, HFL, VYF, KV, KD]`.

## 5. Почему оценка «улучшается» при усилении турбулентности

Таблица выше немонотонна (Ан-24: 4 → 4 → 4 → 2; Ан-2: 1 → 4 → 4 → 1).
Это **не физическая закономерность**, а следствие трёх причин:

1. **Разные усиления на разных уровнях.** `GLAUTO` выбирает ближайший
   уровень из `/APGAIN/`; усиления levels получены независимым поиском
   для каждого `SIGW` без условия монотонности. Например, у Ан-2
   `KV=0.184/KD=4.25` на уровне 0.5 против `KV=1.63/KD=7.16` на 1.5 —
   это разные законы управления, и сравнивать их как «одинаковый
   самолёт при разной погоде» нельзя. Проверка: при принудительной
   подстановке усилений 0.5 в прогон с `SIGW=1.5` Ан-2 даёт VERT=−55.2
   вместо −2.58, то есть эффект целиком определяется усилениями.
2. **Хаотическая зависимость от реализации ветра.** Оценка — это одно
   число `|VERT|` в момент касания. При одном и том же `SIGW=1.5` и
   тех же усилениях, но другой дробной части `RSEED`, Ан-24 даёт:
   `7351.5 → −1.96`, `7351.123 → −9.43`, `0.1 → −65.3`,
   `0.5 → −82.8`, `2.7 → −5.59 м/с`. Разброс в 40 раз. «Улучшение»
   на уровне 1.5 — удачная реализация последовательности, а не
   свойство модели.
3. **Свойство ГПСЧ.** Множитель 997 таков, что затравки, отличающиеся
   на целое число, дают **одинаковую** дробную последовательность
   (`997·Δ` целое). Поэтому `RSEED=7351` и `7352` дают побайтово
   одинаковый результат — сравнения надо менять дробную часть.

Вывод: строка таблицы для фиксированного `SIGW` — один пример, а не
статистика. Для устойчивого вывода нужны серии по 10–20 затравкам и
медиана `VERT`, а не одиночный прогон.

## 6. Ограничение

Для МиГ-15 при любом `SIGW>0` и для части уровней у Ту-104/Ан-24
эталонная посадка не получена: простой автопилот теряет устойчивость
при турбулентности на реальных (лёгких, с высокой производной Cy) ТТХ.
Попытки масштабирования усилений, демпфирования, фильтрации Vy и
подавления порыва не дали устойчивого результата.
После исправления нормализации кватерниона в `CALIB*.PAS` поиск стал
корректным, но полной сходимости по всем клеткам нет.
