# ОЦЕНКА ЗАДАНИЯ И ДЕБРИФИНГ

Дата: 18 ноября 2026 года. Этапы 8–9 плана `docs/PLAN-TRENAZHER-K71.md`.

## 1. Реализация

`SRC/GLSCORE.FTN` вычисляет оценку задания по шести компонентам:

| Компонента | Вес | Что измеряет |
|---|---|---|
| вертикальная скорость касания | 0,28 | `abs(X(2))`, пороги 1,5 / 2,5 / 4,0 м/с |
| точка касания | 0,14 | `abs(X(11))`, предел 3000 м |
| смещение от оси | 0,05 | `abs(X(12))`, предел 50 м |
| интегральная ошибка | 0,24 | СКО отклонения от глиссады, предел 50 м |
| переуправление | 0,14 | сумма `abs(ΔU)` по всем органам, предел 20 рад |
| неплавность | 0,15 | сумма `abs(Δ²U)`, предел 4 рад |

Порог зачёта — 0,60; дополнительно требуется вертикальная скорость
не хуже 4,0 м/с. **Все корректируемые величины лежат в отдельном блоке
`/SCPAR/`** (по коррекции пользователя): пороги, лимиты, веса и порог
зачёта. Результаты — в `/SCORE/`, качества компонент — в `/SCQAL/`,
предыдущие значения управления — в `/OLDU/`.

Накопление идёт в `SCPUT(U)`, вызываемом из `DOSTP` на каждом шаге;
`SCCALC(X)` считает итог в момент касания. Команда инструктора `SCR`
печатает дебрифинг — таблицу по каждой компоненте (значение, качество,
вес, статус `ОТЛ`/`ХОР`/`УДВ`/`НЕУД`) и итоговую строку с баллом,
порогом и зачётом. Все подписи в выводе — русские.

Пример дебрифинга после посадки Ту-104:

```
ДЕБРИФИНГ ЗАДАНИЯ
КОМПОНЕНТ   ЗНАЧЕНИЕ КАЧЕСТВО ВЕС СТАТУС
ВЕРТ         6.37E-01 1.00E+00 2.80E-01 ОТЛ
ТОЧКА        1.96E+03 6.74E-01 1.40E-01 УДВ
ОТ ОСИ       0.00E+00 1.00E+00 5.00E-02 ОТЛ
СКО          2.33E+01 5.35E-01 2.40E-01 УДВ
ПЕРЕУП       1.78E+00 9.11E-01 1.40E-01 ОТЛ
НЕПЛАВ       1.15E+00 7.11E-01 1.50E-01 ХОР
ИТОГО БАЛЛ= 7.870E-01 ПОРОГ= 6.00E-01 ЗАЧЕТ=1
```

Проверка — `python3 TOOLS/exercises.py score`.

## 3. Вывод

Новая оценка строже старой `OCENKA`, которая смотрит только на вертикальную
скорость. T1 и T4 проходят зачёт. T2 проваливается по всем компонентам —
это совпадает с ранее зафиксированным GAP (МиГ-15 в грозе). T3 и T5 при
«отличной» посадке имеют очень большое переуправление и неплавность:
автопилот этих типов самолётов работает с интенсивной коррекцией.

При подготовке дебрифинга обнаружена и исправлена ошибка этапа 8: качество
по смещению от оси (`QY`) вычислялось, но не входило в итоговый балл.
Добавлен вес `WY=0,05` в блоке `/SCPAR/`, остальные веса пересчитаны так,
чтобы их сумма осталась равной 1. Запись — в `docs/corrections.md`.
