# СРАВНЕНИЕ КОНТРОЛЯ ТОЧНОСТИ: «ГЛИССАДА-6» И БИБЛИОТЕКА НИВЦ МГУ

Дата: 18 ноября 2026 года.

## 1. Источники

- **MSU:** `DE13R.FOR` из архива
  `https://num-anal.srcc.msu.ru/lib_na/cat/de_f/de13r.zip`
  (Библиотека численного анализа НИВЦ МГУ, подпрограмма `DE13R`;
  в описании указан метод Рунге–Кутта 4-го порядка с контрольным членом
  Егорова). Локально: `/tmp/de13r/DE13R.utf8.FOR`, 82 строки.
- **Глиссада:** `SRC/GLKM.FTN` (одношаговая оценка Мерсона) и
  `SRC/GLKMA.FTN` (адаптивный режим, блок `/KMCTL/`).

Это **не** подлинная БЭСМ-6 `АД01`: MSU-библиотека современная (Fortran 77,
двойная версия `DE13D`), но она даёт независимую реализацию адаптивного
Рунге–Кутта и позволяет сравнить подходы.

## 2. Сигнатуры

| | Глиссада / АД01 | MSU DE13R |
|---|---|---|
| Вызов | `KUTTAMERSON(N,X,Y,EPS,H,FCT,FIRST)` (catalog 2248) | `DE13R(F,M,XN,YN,XK,HMIN,EPS,P,H,Y,YP,DELTY,YR,DY,IERR)` |
| Производная | `PROIZV(X,U,XD)` через COMMON | подпрограмма `F(X,Y,DY,M)` |
| Допуск | `EPS` | `EPS` |
| Шаг | `H` (вход/выход) | `H` (вход/выход) |
| Нижний предел | `HMIN` в /KMCTL/ | `HMIN` аргумент |
| Пол | нет | `P` — порог, ниже которого компонента не нормируется |
| Авария | `IFAIL=1` | `IERR=65` + `UTDE10` |

Обе сигнатуры содержат `EPS` и `H` — обе реализации **меняют шаг**.
Разница в деталях управления.

## 3. Оценочный член

- **Мерсон (GLKM):** шесть стадий, оценка
  `|2K1 − 9K3 + 8K4 − K5| / 30` — локальная абсолютная погрешность
  за шаг. Наш адаптивный режим дополнительно делает отдельный РК-4 шаг
  (`KMRK4`), то есть **10 вычислений правых частей на принятый шаг**.
- **Егоров (DE13R):** четыре стадии РК-4 с весами
  `BD = (1/6, 1/3, 1/3, 1/6)`, точки `BE = (1/2, 1/2, 1)`.
  Контрольный член накапливается как
  `DELTY = H·(k1 − k2 − k3 + k4)` (коэффициенты `BF = (−1, −1, +1)`),
  то есть оценка **бесплатно** в тех же четырёх стадиях.

## 4. Норма ошибки

- **Глиссада:** `max_i |ERR_i|`, абсолютная величина, сравнивается с `EPS`.
- **MSU:** `DELTY_i / Y_i` при `|Y_i| ≥ P`, затем `max |DELTY_i|`;
  `P` предохраняет от деления на почти ноль.

MSU использует **относительную** ошибку — для ракеты с высотой 15 км
и вертикальной скоростью ~1 м/с это принципиально: абсолютный допуск
по разным компонентам состояния несравним.

## 5. Управление шагом

| | Глиссада (GLKMA) | MSU DE13R |
|---|---|---|
| При обработке | `H·SAFETY·(EPS/ERR)^EXPN`, `SAFETY=0.9`, `EXPN=0.2` | удвоение `H=2H` или деление `H=0.5H` |
| Ограничение роста | `HMAX=1.0`, рост не более ×4 | нет `HMAX`, но шаг ограничен остатком до `XK` |
| Повторы | до `MAXTRY=5` | до достижения `HMIN` |
| При `H<HMIN` | `IFAIL=1`, шаг принудительно | `BUL=.TRUE.`,forced приём, `IERR=65` |
| Доп. условия | — | `B=32`: если `32·ERR < EPS` для всех компонент — удвоить |

Подход MSU проще и дешевле (степень двойки), наш — точнее подстраивается
под величину ошибки, но дороже (десять правых частей против четырёх).

## 6. Проверка на «Глиссаде»

Прогон `ICTRL=3` (Ту-104, штиль, `EPS=1e-4`):

```
OCENKA= 1
KONTROL ERMAX= 9.9337E-05
DTSH= 3.7919E-01
```

Шаг вырос с 0,1 с до 0,379 с, ошибка осталась в пределе допуска.
Регрессия сохранена: 10/10 сценариев, 4/5 упражнений, md5 повтора
`ed36267c…` не изменился — адаптивный режим включается только `ICTRL=3`.

## 7. Что полезно перенять

1. **Относительную ошибку с порогом `P`** — как в MSU. Сейчас наш
   адаптивный режим сравнивает абсолютную ошибку, что непригодно для компонент
   с разными масштабами (высота, скорость, кватернион).
2. **Контрольный член Егорова** как дешёвую альтернативу: четыре стадии
   вместо десяти. Можно предложить второй режим `ICTRL=4` без отдельного
   вызова `KMRK4`.
3. **Явный `HMIN` и код ошибки** — у нас это `IFAIL`, у MSU `IERR=65`
   с диагностикой `UTDE10`; стоит добавить печать причины.

## 8. Оговорка

MSU `DE13R` — современная реализация, а не исходный текст `АД01`.
Подлинная `АД01` найдена только по каталогу диска 2248 (сигнатура и
«автоматический выбор шага»); её объектный модуль лежит в архиве `LIBR1`
и пока не дизассемблирован. Поэтому сравнение выше — сравнение
**семантики**, а не поразрядная сверка алгоритмов.

## 9. Что взято от MSU

Относительная ошибка с порогом `P` (`PFLOOR` в `/KMCTL/`) и печать кода
при `HMIN`. Режим Егорова не добавлялся — оставлена модель Мерсона.
См. `docs/analysis/km-adaptive-calibration.md`.
