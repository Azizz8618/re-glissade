# РЕЗЕРВНЫЙ КОНТРОЛЬ ТОЧНОСТИ ПО КУТТА–МЕРСОНУ

Дата: 18 ноября 2026 года. Поле 3 карты 1 («КОНТРОЛЬ») было зарезервировано
под подпрограмму стандартной библиотеки `АД01`, но эта библиотека в среде
недоступна. Вместо неё реализована локальная резервная подпрограмма
`SRC/GLKM.FTN`.

## 1. Что делает подпрограмма

`SUBROUTINE KUTMER(X,U,DT,ERR)` вычисляет оценку локальной погрешности
интегрирования на одном шаге `DT` для состояния `X(13)` и управления `U(4)`.
Состояние не изменяется. Используются шесть стадий:

```
K1 = DT·F(X)
K2 = DT·F(X + DT·K1/3)
K3 = DT·F(X + DT·(K1+K2)/6)
K4 = DT·F(X + DT·(K1+3·K3)/8)
K5 = DT·F(X + DT·(K1-3·K3+4·K4)/2)
K6 = DT·F(X + DT·(K1+4·K4+K5)/6)
```

Оценка Мерсона:

```
ERR = max_i |(2·K1(i) − 9·K3(i) + 8·K4(i) − K5(i)) / 30|
```

Правая часть `PROIZV` вычисляется шесть раз. Значение `ERR` — максимальная
по компонентам вектора состояния абсолютная погрешность за шаг.

## 2. Включение

| Конфигурация | Значение поля 3 | Эффект |
|---|---|---|
| Классическая колода `JOB/GLISSADA.B6` | `>0` | на каждом шаге вызывается `KUTMER`, на касании печатается `KONTROL KUTTA-MERSON ERMAX=` |
| Диалог `GLDIAL.PAS` | `2` | то же; значения 0 и 1 сохраняют прежний смысл |
| Все исторические сценарии | `0` | контроль выключен, чтобы не менять эталонные метрики |

Максимум `ERR` за прогон накапливается в `ERMAX`.

## 3. Пример

Диалог, `KTIP=3`, `SIGW=0`, `ICTRL=2`, `DT0=0.60`:

```
OCENKA= 1
KONTROL ERMAX= 2.4953E-05
```

Порядок величины `10^-5` м на шаг 0,1 с соответствует шагу РК-4 на гладкой
траектории.

## 4. Ограничение и уточнение по подлинной АД01

Реализован **контроль** (оценка), а не адаптивное изменение шага. Шаг
остаётся фиксированным 0,1 с — это сохранено ради совпадения с эталонными
прогонами. Переход на адаптивный шаг потребует перекалибровки автопилота
и пересчёта всех эталонов.

**Найдено на диске 2248 (18 ноября 2026 года).** В каталоге стандартной
библиотеки, зона `0573(8)`, строки `0420–0450` (кодировка KOI-7):

```
1. AD01 ПРОЦЕДУРА ИНТЕГРИРОВАНИЯ СИСТЕМЫ О.Д.У. МЕТОДОМ КУТТА-МЕРСОНА
        С АВТОМАТИЧЕСКИМ ВЫБОРОМ ШАГА
        KUTTAMERSON(N,X,Y,EPS,H,FCT,FIRST).
2. AD02 ... МЕТОДОМ ЭЙЛЕРА НА ОДНОМ ШАГЕ (С ПОСТОЯННЫМ ШАГОМ)
3. AD03 ... РУНГЕ-КУТТА НА ОДНОМ ШАГЕ (С ПОСТОЯННЫМ ШАГОМ)
4. AD04 ИНТЕГРИРОВАНИЕ ... С АВТОМАТИЧЕСКИМ ВЫБОРОМ ШАГА ... RUKUT(...)
```

То есть подлинная `АД01` **меняет шаг автоматически**: в сигнатуре есть
`EPS` (допуск) и `H` (шаг), а в описании прямо сказано «с автоматическим
выбором шага». Наш `GLKM` — одношаговая оценка, по поведению ближе к
`AD02/AD03`, чем к `AD01`.

Сигнатура подлинной процедуры (`N,X,Y,EPS,H,FCT,FIRST`) теперь известна;
при желании можно построить более точную реконструкцию с адаптивным шагом
как отдельный режим, не включая его по умолчанию.
