ПАКЕТ ГЛИССАДА-6. ВЕРСИЯ НА ФОРТРАНЕ ИПМ (БЭСМ-6, ДИСПАК)

1. НАЗНАЧЕНИЕ
   Реконструкция игры "Глиссада" в технологиях 1975-1980 гг.:
   заход на посадку по глиссаде 3 град, 4 типа самолетов
   (МИГ-15, ИЛ-28, ТУ-104, АН-24), 6 степеней свободы,
   вывод кадра на АЦПУ и короткой строки на дисплей, оценка
   посадки. Транслятор - ФОРТРАН ИПМ; средства новее стандарта
   эпохи не применялись (нет блочных IF, нет типа CHARACTER,
   русский текст - только Холлеритом для АЦПУ).

2. СОСТАВ
   SRC/GLMAIN.FTN   - главная программа, Рунге-Кутта 4, шаг 0.1 с
   SRC/GLPROIZ.FTN  - правые части уравнений (6 ст. свободы),
                      двигатели ТРД/ТВД
   SRC/GLINITD.FTN  - данные 4 типов самолетов (оценки)
   SRC/GLNUM.FTN    - адаптеры СБ: ATM (АЗ01), NR (АВ07);
                      запасные программы (МСА, Лемер);
                      турбулентность Орнштейна-Уленбека
   SRC/GLAUTO.FTN   - автопилат (режим АВТОМАТ), программа
                      пилотирования с карт (режим ПРОГРАММА)
   SRC/GLOUT.FTN    - кадр АЦПУ, строка на дисплей, оценка посадки
   JOB/GLISSADA.JOB - готовая колода задания ДИСПАК (Ту-104, авто)
   DATA/GLIS1.DAT   - Ту-104, режим АВТОМАТ
   DATA/GLIS2.DAT   - МиГ-15, режим ПРОГРАММА (игра)

3. КАРТЫ ИСХОДНЫХ ДАННЫХ
   Карта 1 (5I5):
     поле 1 ТИП      1-МИГ-15, 2-ИЛ-28, 3-ТУ-104, 4-АН-24
     поле 2 РЕЖИМ    1-АВТОМАТ, 2-ПРОГРАММА
     поле 3 КОНТРОЛЬ зарезервировано (Кутта-Мерсон, АД01, этап 1)
     поле 4 ПЕЧАТЬ   период кадра АЦПУ, с (0 - только касание)
     поле 5 БИБЛ.СБ  1 - вызовы СБ, 0 - запасные программы
   Карта 2 (4F8.0): ВРЕМЯ МАКС, СЕМЯ СЛУЧ.ЧИСЕЛ, СИГМА ТУРБУЛЕНТНОСТИ
     (М/С, 0 - штиль), НАЧАЛЬНАЯ ТЯГА (0-1)
   Режим ПРОГРАММА: далее карты (5F8.0): Т, РУЛЬ ВЫС (ГР),
     ЭЛЕРОНЫ (ГР), РУЛЬ НАПРАВЛЕНИЯ (ГР), ТЯГА (0-1);
     линейная интерполяция между картами; конец - карта с Т<0.

4. ВЫЗОВЫ БИБЛИОТЕКИ СБ (ТОМ 2048)
   CALL ATM(H,TK,RHO) - стандартная атмосфера (катал. АЗ01)
   CALL NR(RN)        - нормальное случайное (катал. АВ07)
   Сигнатуры взяты по каталогу (Мазный, с.128-139) и подлежат
   проверке на этапе 1. Все обращения собраны в SRC/GLNUM.FTN -
   при расхождении правится только этот файл.

5. УСТРОЙСТВА
   5 - ввод карт (задание ДИСПАК), 6 - АЦПУ, 12 - дисплей.
   Привязку уточнить по описанию транслятора ФОРТРАН ИПМ (этап 1).

6. УПРОЩЕНИЯ МОДЕЛИ (ЗАДАНЫ СОЗНАТЕЛЬНО, СТИЛЬ ЭПОХИ)
   - тензоры инерции диагональные;
   - аэродинамика: линейные производные устойчивости + срыв;
   - двигатели: упрощенные дроссельные характеристики;
   - коэффициенты всех 4 типов - оценки по открытым данным;
   - русские тексты - Холлеритом (ГОСТ 10859); при отказе
     транслятора заменить на латинскую транслитерацию.

7. КАК ИГРАТЬ
   Режим ПРОГРАММА: пилотирование задается заранее колодой карт;
   кадр АЦПУ показывает положение относительно глиссады курсором
   (звездочка в масштабе 5 м/знак). Подбор карт касания = игра.
