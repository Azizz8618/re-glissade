3. НАХОДКИ ПО СРЕДЕ
   3.1 Библиотека СБ (ATM АЗ01, NR АВ07) в комплекте образов
       Монитор-80 ИАЭ не найдена (поиск по томам 2048, 2053,
       2248, 2099). Том 2048 = пакет Д-2048: библиотеки
       Монитора *LIBRARY:n (ФОРЭКС = *LIBRARY:7, зоны
       1205-1241). Варианты: доустановка СБ отдельным томом
       либо работа с резервным адаптером GLNUMR.
   3.2 Ввод информации задачи (карты после *execute): runtime
       читает ЛУН 5 по Э70 КУС (устройство 45, зона 0). В среде
       ЛУН 45 не привязан и ничем не заполняется. Пробы:
       45(2099) - "ИСПОРЧЕН РЕКОРД" (каталог системы);
       45(45-ЗП) пустой и с картами в упаковке А3 (24 слова на
       карту) - "ИСПОРЧЕН РЕКОРД". Формат записи МОNRЕАД*
       подлежит восстановлению; собраны дампы кода (память
       задачи 05416-05577) и выполнено предварительное
       дизассемблирование. СТП-паспорта (зс5) в пакетных
       прогонах не участвуют (edit-режим эмулятора).
   3.3 Обходной путь эпохи: данные на МЛ, чтение с ЛУН ленты -
       после подтверждения формата записей МЛ.
   3.4 УТОЧНЕНИЕ (продолжение этапа 0): библиотека с АТМ и NR
       НАЙДЕНА на томе 2248. Источники: (а) контрольная выдача
       tests/librefer-2248 (каталог библиотеки Монитора-80,
       кросс-ссылки: АТМ -> А/PROCRT, ЕХР*, LN*, SQRТ*;
       NR -> А/I0, А/PROCRT, А/SIGN, ЕNТIЕR*, SQRТ*); рядом
       NORM/GАUSS, матричные и др. члены; (б) besmtool search
       2248: записи каталога в зонах 0470-0472 (кодировка
       TEXT). Поиск п. 3.1 прошел мимо: вскрывались зоны
       *LIBRARY тома 2048, каталог тома 2248 не просматривался.
   3.5 Подключение тома 2248 в задание (ЛЕН 42(2248)) сборку
       НЕ решает: в карте загрузки по-прежнему ОТСУТСТВУЕТ
       АТМ/NR - загрузчик ФОРЭКС перебирает только *LIBRARY
       системного тома (2048). Нужен штатный способ указать
       библиотеку тома (операции БИБЛИОТЕКИ/директивы
